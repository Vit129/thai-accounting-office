คู่มือเริ่มใช้งานผู้ช่วยบัญชี

สำหรับคนที่เพิ่งใช้ AI ทำงานครั้งแรก อ่านจบใน 5 นาที ไม่ต้องรู้เรื่องคอมพิวเตอร์เพิ่ม

ผู้ช่วยนี้คืออะไร
คือ Claude (AI) ที่ถูกสอนงานบัญชีและภาษีไทยไว้แล้ว คุณพิมพ์สั่งเป็นภาษาไทยเหมือนฝากงานเพื่อนร่วมงาน เช่น "ปิดงวดเดือนนี้" มันจะอ่านเอกสาร ลงบัญชี คำนวณภาษี แล้วมารายงานผล คุณเป็นหัวหน้า มันไม่ยื่นภาษี ไม่ส่งอีเมล และไม่จ่ายเงินเองเด็ดขาด ต้องรอคุณกดยืนยันทุกครั้ง
มันยังจำงานทุกชิ้นถาวร (ใช้ไฟล์ไหน ชีทไหน เมลหัวข้ออะไร ใช้สูตรอะไร เจอปัญหาอะไร) และเก่งขึ้นเองทุกงาน จากที่คุณแก้ให้ ข้อมูลทั้งหมดเก็บในโฟลเดอร์งานของคุณเอง

เริ่มต้นใน 4 ขั้น (ทำครั้งเดียว)

  1. ติดตั้งผู้ช่วย

    ใน Claude Desktop เปิด Customize → Plugins → Add → Upload plugin แล้วเลือกไฟล์ thai-accounting-office.zip ที่ได้รับ (ถ้าเคยติดตั้งตัวเก่า ให้กด ⋯ → Remove ก่อน ข้อมูลในโฟลเดอร์งานไม่หาย)

  2. สร้างโฟลเดอร์งาน

    สร้างโฟลเดอร์ใหม่ไว้เก็บงานบัญชี ตั้งชื่อสั้น ๆ เช่น OneDrive\Accounting (อย่าตั้งยาวหรือซ้อนหลายชั้น) แล้วเลือกโฟลเดอร์นี้ให้ Claude ใช้ตอนเริ่มแชทใหม่ ทุกไฟล์ที่ผู้ช่วยสร้างจะอยู่ในนี้

  3. ใส่ไฟล์ CLAUDE.md ในโฟลเดอร์งาน

    ไฟล์นี้คือ "ใบสั่งงานถาวร" ที่ Claude อ่านทุกครั้งที่เปิดโฟลเดอร์ ทำให้มันรู้ว่าต้องทำงานแบบไหน กดดาวน์โหลดแล้วย้ายไฟล์เข้าโฟลเดอร์งาน

    ดูว่าในไฟล์เขียนอะไร
    # Accounting work folder

Template version: 2026-10-19.5

Accounting work assisted by the Thai Accounting Office plugin. Talk to the user in Thai (plain
words, the user is not technical); write files in English unless a document must be Thai.

- Start every job with the `company-profile` skill; background: its `references/handoff.md`.
- Company facts: `Accountant/company-facts.md` (wins over any `<…>` gap in the plugin; its `## Tax rate overrides`
  win over the rates in the skills). Tasks and deadlines: `Accountant/register.xlsx`. Lessons:
  `Accountant/lessons/`. Plugin mismatches: `Accountant/tune-up.md`.
- Memory (permanent, in this folder): `Accountant/memory/`. Look it up before a job and record after it
  with the `accountant-memory` skill. Every job leaves a ledger entry in `Accountant/memory/ledger/` with
  the files (sheet and range), email subjects, formulas, checks and problems it used.
  Search first (`accountant-graph`): names, document numbers, forms and periods are looked up in the
  catalog and then in this folder and the mailbox before the user is asked for a file.
- The `Mode:` line in `company-facts.md` says whether this is one company (in-house, "client" means
  the company) or many clients.
- Never file, send outside, pay or approve payment, edit the payroll file, or change a closed
  period without the user's explicit yes; give the why with every proposal.
- Salaries, ID numbers and bank account numbers stay in this folder's source files only; never
  in lessons, tune-up reports or email drafts to people outside the approver list.
- Report as ผลลัพธ์ / หลักฐาน / ต้องให้คุณตัดสินใจ; figures pass `reconcile-check` and the
  `auditor` agent before they are reported.

    ไม่แน่ใจว่าทำถูกไหม ไม่เป็นไร ข้ามขั้นนี้ได้ ผู้ช่วยจะสร้างไฟล์นี้ให้เองในขั้นถัดไป

  4. พิมพ์ "เริ่มงาน" ในช่องแชท

    Claude จะอ่าน CLAUDE.md แล้วเปิดโหมดตั้งค่าเอง โดยถามข้อมูลบริษัทเป็นข้อความเดียว (ชื่อบริษัท ใครเป็นผู้อนุมัติ ใช้โปรแกรมอะไร ฯลฯ) ตอบเท่าที่รู้ ข้อที่ไม่รู้พิมพ์ "ไม่รู้" ได้

    เริ่มงาน
เสร็จแล้ว! ต่อไปนี้เปิดโฟลเดอร์งานแล้วสั่งงานได้เลย ไม่ต้องตั้งค่าอีก

ทดสอบก่อนใช้งานจริง (10 ข้อ ใช้โฟลเดอร์ทดลอง)

สร้างโฟลเดอร์ทดลองที่ไม่มีข้อมูลจริง วางไฟล์ invoice.txt ที่เขียนว่า "ใบแจ้งหนี้ CloudHost ตุลาคม INV-0042" แล้วกดคัดลอกทีละข้อไปวางในแชท ดูว่าเห็นตามที่เขียนไหม

  1. 1เริ่มงานควรเห็น: ถามข้อมูลบริษัทเป็นข้อความเดียว แล้วสร้างโฟลเดอร์ Accountant ในโฟลเดอร์ทดลอง
  2. 2เพิ่มผู้ขายควรเห็น: ได้รหัส P-1 และมีชื่อไทยกับอังกฤษอยู่ในไฟล์ parties.md
  3. 3ทำดัชนีเอกสารควรเห็น: indexed 1 new file และมีรายการ K-1
  4. 4ค้นด้วยชื่อไทยควรเห็น: เจอ invoice.txt และ P-1 ทั้งที่ไฟล์เขียนว่า CloudHost (ข้อสำคัญที่สุด)
  5. 5ทำงานทดลอง 1 งานควรเห็น: รายงาน 3 ส่วน แล้วบอก "บันทึกงาน J-…" และมีไฟล์ในโฟลเดอร์ ledger
  6. 6ถามย้อนที่มาควรเห็น: บอกงาน J-… ไฟล์ ชีท ช่วงเซลล์ และผลตรวจ
  7. 7สอนให้จำควรเห็น: บอกว่าบันทึกบทเรียนอะไร และมีไฟล์ในโฟลเดอร์ lessons
  8. 8ตรวจความครบควรเห็น: memory is consistent หรือรายการที่ขาด
  9. 9แผนที่งานควรเห็น: ได้ไฟล์ map.html เปิดในเบราว์เซอร์ได้
  10. 10ข้อที่ต้องปฏิเสธควรเห็น: ปฏิเสธ ไม่เก็บเลข 13 หลัก
ถามเพิ่ม: "คุณมีเครื่องมือชื่อ accountant_ อะไรบ้าง" ควรเห็น 15 ตัว ถ้าไม่เห็น แปลว่าเครื่องไม่มี Python หรือเครื่องมือไม่เริ่ม ระบบยังทำงานได้แบบทำมือ แต่ช่วยแจ้งผู้ดูแลด้วย
ส่งผลกลับ: ข้อไหนไม่ผ่าน ข้อความที่เห็นจริง และภาพชื่อไฟล์ในโฟลเดอร์ Accountant/memory (ไม่ต้องส่งเนื้อหาจริง) คำสั่งทดสอบสำหรับเทอร์มินัลอยู่ใน README

ใช้งานประจำวัน

  • พิมพ์ภาษาไทยธรรมดา ไม่ต้องจำคำสั่ง ไม่ต้องพิมพ์ / ก็ได้ ถ้าไม่รู้จะพิมพ์อะไร ใช้ประโยคตัวอย่างด้านล่าง
  • มันจะตรวจเองก่อนรายงาน ตัวเลขต้องกระทบยอดผ่านและมีผู้ตรวจอิสระดูอีกชั้น แล้วรายงานเป็น 3 ส่วน: ผลลัพธ์ · หลักฐาน · เรื่องที่ต้องให้คุณตัดสินใจ
  • ทำผิดบอกได้เลย เช่น "ไม่ใช่แบบนี้ ที่นี่ทำแบบ..." มันจดเป็นบทเรียนและทำให้ถูกในครั้งหน้า (ลบบทเรียนได้เสมอ)
  • ทุกงานมีบันทึก เมื่อจบงาน มันจะบอกว่า "บันทึกงาน J-…" นั่นคือรายการในสมุดบันทึกงานที่ถามย้อนได้ ถ้าไม่เห็นข้อความนี้ พิมพ์ "บันทึกงานนี้ลงความจำ"
  • ตรวจก่อนใช้จริงเสมอ อัตราภาษีและวันครบกำหนดในผู้ช่วยเป็นค่าตั้งต้น ตรวจกับประกาศกรมสรรพากรปีปัจจุบันก่อนยื่น ความรับผิดชอบทางวิชาชีพยังเป็นของคุณ
ห้ามใส่ลงในแชทหรือไฟล์ที่ส่งต่อ: รหัสผ่านธนาคาร เลขบัตรประชาชนและเงินเดือนของคนอื่นที่ไม่เกี่ยวกับงานนั้น ข้อมูลเหล่านี้เก็บในโฟลเดอร์งานเท่านั้น

ผู้ช่วยจำอะไรไว้ ถามย้อนได้ยังไง

ทุกอย่างเป็นไฟล์ข้อความในโฟลเดอร์ Accountant/memory ของคุณ เปิดอ่าน แก้ หรือลบรายการไหนก็ได้

  • สมุดบันทึกงาน ทุกงานที่จบ ติดขัด หรือหยุด มีหนึ่งรายการ: เมื่อไร ทำอะไร อ่านไฟล์ไหน ชีทไหน ช่วงเซลล์ไหน เมลหัวข้ออะไร ใช้สูตรอะไร ตรวจผ่านไหม เจอปัญหาอะไรและแก้ยังไง
  • วิธีปฏิบัติต่อผู้ขาย / ลูกค้าแต่ละราย เช่น หัก ณ ที่จ่ายเท่าไร มี VAT ไหม ลงบัญชีไหน พร้อมหลักฐาน
  • ข้อตัดสินใจ พร้อมเหตุผล ใครอนุมัติ เมื่อไร
  • รายการประจำเดือน และช่วงยอดปกติ ถ้ายอดผิดปกติมันจะถามคุณก่อน ไม่ลงบัญชีเงียบๆ
  • สถานะแต่ละงวด ฟอร์มที่ยื่น เลขอ้างอิง และยอดยกไปงวดหน้า (เดือนหน้ามันเทียบยอดยกมาให้เอง)
  • แหล่งข้อมูลและสูตรที่ใช้ซ้ำ ไฟล์ไหนอยู่ช่วงเซลล์ไหน สูตรและอัตราอ้างอิงมาตราอะไร

ถามย้อนได้เป็นภาษาไทย เช่น "ตัวเลขช่อง D14 ในใบสำคัญจ่ายนี้มาจากไหน" "ผู้ขายรายนี้เคยมีปัญหาอะไร" "ใช้สูตรหัก ณ ที่จ่ายที่ไหนบ้าง" มันค้นสมุดบันทึกแล้วตอบพร้อมเลขงาน (เช่น J-20261031-2)

สิ่งที่ไม่ถูกจด: เงินเดือน เลขบัตรประชาชน เลขบัญชีธนาคาร รหัสผ่าน และเนื้อหาในอีเมลหรือเอกสาร (จดแค่ชื่อไฟล์และหัวข้อเมลเพื่อให้ค้นเจอ) ถ้าทำหลายลูกค้า ความจำแยกตามลูกค้า ไม่ปนกัน
ควรทำ: สำรองโฟลเดอร์งานและ Accountant/ ไว้อีกที่หนึ่งทุกสิ้นเดือน เพราะความจำอยู่ที่นี่ที่เดียว ตรวจสมุดบันทึกเป็นครั้งคราวว่าจดครบ การจดเป็นไปตามคำสั่งของผู้ช่วย ไม่ได้บังคับ 100%
เก่งขึ้นเองยังไง: เมื่อคุณแก้งาน หรือการตรวจไม่ผ่านแล้วแก้ ผู้ช่วยจดบทเรียนหนึ่งบรรทัดแล้วบอกคุณ ครั้งหน้าทุกงานอ่านบทเรียนก่อนทำ ทุกวันจันทร์พิมพ์ "ทบทวนประจำสัปดาห์" มันดูสมุดบันทึกว่าแต่ละงานใช้บ่อยแค่ไหน ปัญหาไหนเกิดซ้ำ แล้วเสนอสิ่งที่ควรปรับ (คุณเป็นคนอนุมัติ)

ค้นหาเอกสารและเมลได้ (แผนที่งาน)

ค้นด้วย ชื่อ เลขที่เอกสาร ฟอร์ม หรืองวด ในไฟล์ PDF อีเมล Word Excel CSV และโน้ต

  • ค้นก่อนเริ่มทุกงาน ผู้ช่วยค้นในแผนที่เอกสารของคุณก่อน แล้วค้นสดในโฟลเดอร์งาน ที่เก็บไฟล์ และกล่องเมล จึงไม่ต้องบอกว่าไฟล์อยู่ไหน ถ้ามีหลายตัวเลือกมันจะแสดงให้คุณเลือก (ไม่เกิน 5 รายการ)
  • ชื่อผู้ขายหลายแบบ ชื่อไทย อังกฤษ และชื่อย่อของรายเดียวกันจดไว้ครั้งเดียว ค้นด้วยชื่อไหนก็เจอ
  • ใช้เครื่องมือช่วย การค้น การใส่เลขรหัส และการเขียนสมุดบันทึกงาน ทำโดยสคริปต์ที่ติดมากับผู้ช่วย (ต้องมี Python ในเครื่อง ถ้าไม่มีมันทำมือตามขั้นตอนเดิม) ค้นด้วยชื่อไหนของผู้ขายก็เจอ ค้นในไฟล์ Word Excel และข้อความได้ ส่วน PDF และรูปค้นได้แค่ชื่อไฟล์ และ "ขอดูแผนที่งาน" จะได้ไฟล์ map.html เปิดในเบราว์เซอร์ได้
  • ทำดัชนีย้อนหลัง พิมพ์ "ทำดัชนีเอกสาร" ให้มันอ่านโฟลเดอร์หรือกล่องเมลทีละเดือน หยุดตอนไหนก็ได้
  • ถามความเชื่อมโยง เช่น ทุกอย่างที่เกี่ยวกับผู้ขายรายนี้ หรือถ้าเปลี่ยนอัตราภาษีนี้จะกระทบงานและงวดไหน และ "ขอดูแผนที่งาน" เพื่อให้สร้างหน้าภาพความเชื่อมโยง (ครั้งละผู้ขายหนึ่งราย หรือหนึ่งงวด)
ไฟล์สแกนที่อ่านไม่ได้มันจะบอกตรงๆ ไม่เดา และไม่เก็บเนื้อหาในเมลหรือเอกสาร เก็บแค่ชื่อเรื่อง ชื่อไฟล์ ชื่อผู้ขาย และเลขที่เอกสารเพื่อให้ค้นเจอ

ไม่รู้จะพิมพ์อะไร? กดคัดลอกแล้ววางในช่องแชท

งานแต่ละชิ้นเดินยังไง (workflow)

ทุกงานเดินแบบเดียวกัน ป้าย คุณ คือจุดที่ต้องรอคุณ ส่วนที่เหลือ Claude ทำเอง

  1. Claudeค้นเอกสารและอ่านบทเรียน ข้อมูลบริษัท ความจำก่อนเปิด Accountant/company-facts.md บทเรียนครั้งก่อน และความจำที่ตรงกับงาน (ผู้ขายรายนี้ทำยังไง เคยตัดสินใจอะไร ยอดยกมา) แล้วทำตาม จึงไม่ถามเรื่องเดิมซ้ำ
  2. คุณตอบคำถามครั้งเดียวถ้าข้อมูลไม่ครบ (งวดไหน เอกสารอะไร) จะรวมเป็นคำถามเดียว พร้อมคำตอบที่แนะนำ ไม่ถามทีละข้อ
  3. Claudeลงมือทำผู้ช่วยอ่านเอกสารจำนวนมากแยกข้อมูลออกมา ส่วนการลงบัญชีและตีความภาษี Claude ทำเอง
  4. Claudeตรวจตัวเลขกระทบยอดทุกตัวเลขที่จะยื่น ส่ง หรือรายงาน ไม่ผ่านจะแก้ 1 ครั้ง ถ้ายังไม่ผ่านจะรายงานตามจริง
  5. Claudeผู้ตรวจอิสระดูอีกชั้นauditor ตรวจงานเทียบกับที่คุณสั่ง ก่อนบอกว่าเสร็จ
  6. คุณรับรายงาน 3 ส่วน แล้วตัดสินใจผลลัพธ์ (1 บรรทัด + ลิงก์ไฟล์) · หลักฐาน (เช็คอะไรผ่านบ้าง) · เรื่องที่ต้องให้คุณตัดสินใจ (พร้อมเหตุผล) จะยื่น ส่ง จ่าย หรืออนุมัติ คุณเป็นคนกดเอง
  7. Claudeจดบันทึกงานเขียนลงสมุดบันทึกงานทุกครั้ง: ไฟล์ ชีท ช่วงเซลล์ หัวข้อเมล สูตร ผลตรวจ ปัญหา แล้วบอกว่า "บันทึกงาน J-…" ถ้างานนั้นตัดสินใจอะไรที่ยืนยันแล้ว จะบันทึกไว้ในความจำด้วย
  8. Claudeเก็บบทเรียนถ้าคุณแก้งาน จะจดบทเรียน 1 บรรทัดแล้วบอกคุณ ถ้าไม่มีจะบอกว่า "ไม่มีบทเรียนใหม่" ครั้งหน้าจะทำถูกเอง
ช่วง 2 เดือนแรก: ตอนเย็นพิมพ์ "สรุปวันนี้" (ไม่เกิน 5 นาที) Claude จะสรุปงาน ถามข้อมูลบริษัทที่ยังขาดไม่เกิน 3 ข้อ และจดสิ่งที่ยังไม่ตรงกับบริษัท ทุกวันศุกร์พิมพ์ "สรุปสัปดาห์" เพื่อได้ไฟล์รายงานส่งให้คนที่ทำผู้ช่วยนี้ปรับปรุงให้ ปรับได้ตลอดเวลาที่เจออะไรไม่ตรง แค่พิมพ์บอก
Claude จะไม่ทำเองเด็ดขาด (ต้องรอคุณกดยืนยัน): ยื่นภาษี / ประกันสังคม / DBD · ส่งอีเมลหรือไฟล์ออกไปข้างนอก · จ่ายเงินหรืออนุมัติจ่าย · แก้ไฟล์เงินเดือน · ลบหรือแก้ข้อมูลงวดที่ปิดแล้ว · เรื่องภาษีที่ตีความได้หลายทาง
