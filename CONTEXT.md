# Context

- This repository is the source for the generic Thai Accounting Office plugin.
- `README.md` is the user-facing installation guide; `CONTRIBUTING.md` defines maintenance and delivery commands.
- Do not commit customer records or company-specific work-folder contents.
- The package is a conversational plugin. It has no web dev server or visual UI to preview.
- Release instructions describe version promotion and package building; this repository has no automated release publisher.
